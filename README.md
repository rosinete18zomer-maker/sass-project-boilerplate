# Sass Project Boilerplate

Este é um repositório base configurado com Sass (SCSS) seguindo a arquitetura 7-1 simplificada.

## Como usar

1. Clone o repositório
2. Instale as dependências:
   ```bash
   pnpm install
   ```
3. Para compilar o Sass uma vez:
   ```bash
   pnpm run sass:build
   ```
4. Para observar mudanças em tempo real:
   ```bash
   pnpm run sass:watch
   ```

## Estrutura de Pastas

- `scss/`: Contém todos os arquivos fonte Sass.
- `css/`: Onde o CSS compilado será gerado.
- `index.html`: Arquivo HTML de exemplo.
